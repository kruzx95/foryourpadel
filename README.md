# For You Padel (FYP)

Website resmi FYP Padel Court Tasikmalaya — Lapangan padel premium dengan standar internasional.

## Prasyarat

- [Node.js](https://nodejs.org/) (versi 18 ke atas disarankan)
- npm (bawaan dari instalasi Node.js)

## Cara Menjalankan Secara Lokal

1. **Install dependensi**:
   ```bash
   npm install
   ```

2. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka peramban (browser) di URL yang ditampilkan di terminal, biasanya:
   [http://localhost:5173/](http://localhost:5173/)

## Perintah Lainnya

- **Build untuk Production**:
  ```bash
  npm run build
  ```
- **Preview Hasil Build**:
  ```bash
  npm run preview
  ```
